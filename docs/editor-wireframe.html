Note di handoff

1 pin ↔ 1 nota · struttura reale del prodotto

①

Riga contesto: indietro contestuale (Torna ai cataloghi / ai miei poster / indietro) + SearchBar centrata max-w-lg con dropdown ricerche recenti su focus. Nessuna toolbar editor: le azioni stanno sotto l'anteprima. Ctrl/Cmd+S = salva config.

②

Colonna Poster: tab Clean/lingue con conteggi (solo gruppi esistenti); griglia tile 2:3 (3 col, 4 ≥1536px) con badge "Best fit" (score ≥0.45) e ring sulla tile migliore; auto-rotate ON/OFF, ordinamento TMDB/Best fit, "Scegli il miglior poster", +12 load more, esclusi con Ripristina.

③

Anteprima: colonna centrale 400–480px reale (qui scalata), stage 2:3 con glow ambient (blur poster ~20% alle spalle); metadata SOLO LETTURA — titolo, anno · tipo, link TMDB/IMDB; genere/voto non compaiono in editor, entrano nei badge lato server. Azioni sotto: Salva poster (primary), Test URL, Copia link config → /api/poster/{type}/{imdb_id}?config=token.

④

Pannello Dettagli: tab Logo (sempre) · Badge e Transform solo per poster clean (Transform solo con logo selezionato). Contenuti: griglia loghi con rimozione, stili badge (pill/bar/colored/bordo/vetro), transform con slider. L'accent UI si adatta al colore del poster (.ui-accent).

⑤

Toolbar app — layer flottante in alto a destra (absolute top-4 right-4): Copia URL, Installa catalogo, Profilo, Proxy, contatore Miei poster, Impostazioni; su mobile scende a riga sotto l'header. Icone 36px, target tocco ≥44px.

⑥

Island stato — layer flottante in basso a destra (fixed bottom-5 right-5): Aggiorna liste, /status, Lingua (dropdown verso l'alto). Due island separate per funzione: non fondere.

Legenda — l'arancio segna solo i pin e le note corrispondenti; tutto il resto è greybox strutturale. Bordo tratteggiato = layer flottante. Colonne reali: 300 / 400–480 / 300 su max 1360px (wireframe proporzionale) → 2 col ≤1160px (anteprima full-width), 1 col ≤860px. Hover (o Tab) su pin, blocco o nota evidenzia la coppia.
